# **App Name**: BrandNarrator

## Core Features:

- Interactive Story Gathering: AI-powered conversational tool to extract the startup's story through a guided interaction with the user, gathering key information about the company's origins, mission, and values.
- Brand Story Generation: Generates a compelling narrative of the brand's story based on the information gathered. AI acts as a creative partner to the founder to weave an emotional and factual narrative that users find inspiring and authentic.
- Social Media Post Scheduler: Allows users to schedule social media posts across various platforms to share the brand's story.
- AI Prompt Generator: Provides AI-optimized prompts tailored for different AI platforms, helping users generate relevant marketing content more effectively.
- Content Analytics Dashboard: A dashboard to track and analyze the performance of shared content, providing insights into audience engagement.
- Platform Integrations: Easy integrations to widely used marketing and sales platform to increase performance.

## Style Guidelines:

- Primary color: Vivid purple (#9D1DD1) to represent creativity and innovation, crucial for a startup-focused app.
- Background color: Light lavender (#E6D7EA) for a gentle, uncluttered backdrop that complements the primary color.
- Accent color: Electric blue (#3466FF) to draw attention to key features and CTAs.
- Headline font: 'Space Grotesk' sans-serif for a contemporary, computerized, techy look; Body font: 'Inter' sans-serif to complement 'Space Grotesk', suitable for body text where longer lines of text are used.
- Modern, minimalistic icons that reflect the digital and innovative nature of startups. Each icon will clearly represent its function within the app, using line art.
- Clean and intuitive layout, emphasizing ease of navigation and content discovery. Each feature must be readily available.
- Subtle, modern animations and transitions to improve user experience and make the interface more engaging. For instance, gentle fades and slides when loading new content or transitioning between screens.
